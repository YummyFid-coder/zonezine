# ZoneZine

Independent English-language Fortnite reference site. This first release includes a Wiki-style homepage and five Kasane Teto guides, illustrated unlock steps, a reward checklist, a 360-degree Outfit preview and a four-song player.

## Cloudflare Pages

- Framework preset: None
- Build command: leave blank
- Build output directory: .
- Production branch: main
- Intended custom domain: zonezine.org

This repository contains the deployable static site. The local-only image editor and preview server are not included. Media attribution is retained in captions and the assets source records. Third-party media playback depends on its provider.
